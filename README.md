
# Expense Tracker

## About the Project
Expense Tracker is a simple web-based application developed using HTML, CSS, and JavaScript. It helps users manage their daily expenses by allowing them to add, view, and track their spending.

The main purpose of this project is to make expense management easier and help users keep track of their money.

## Features
- Add new expenses.
- Enter expense name and amount.
- Select expense category.
- View a list of all expenses.
- Calculate total expenses automatically.
- Delete expenses.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.

## Technologies Used
- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Functionality and expense calculations.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start adding and managing your expenses.

## How It Works

1. Enter the name of the expense.
2. Enter the amount spent.
3. Select the expense category.
4. Click the Add Expense button.
5. The expense will appear in the expense list.
6. The total amount will update automatically.
7. You can delete expenses whenever required.
